# GMP Auto Brake and Landing Gear Panel HID Protocol Documentation

> Automatically generated by the WINGFLEX production tool
> Protocol format version: 1.0

# Product Features

GMP is a product that fully supports standard control protocols. It has the following features:

1. Supports direct in-game binding of buttons and axis inputs.
2. Supports quick development and integration using almost any programming language.
3. INPUT reports are sent only when the data changes.
4. Once a FEATURE report is sent, the device maintains its lighting state. The automatic standby timeout can be configured as needed.

# Design Specifications

1. Buttons and axes use the standard HID INPUT protocol and are mapped as joystick axes and buttons. Users can bind them directly, and they can be recognized by games.
2. Button lighting uses a custom HID FEATURE protocol and is controlled by the host application.
